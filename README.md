Clínica - Modelo de Gestión de Información

Descripción
Este proyecto corresponde a la implementación del modelo del sistema para la gestión de información de una clínica, desarrollado en Java como parte de la asignatura Construcción de Software II. El objetivo del proyecto es representar mediante programación orientada a objetos las entidades, atributos y relaciones descritas en el dominio del problema.

Estructura del Modelo
El sistema incluye las siguientes entidades principales:
Person (Clase abstracta)
Employee
Patient
InsurancePolicy
Order
OrderItem (Clase abstracta)
MedicationOrder
ProcedureOrder
Enumeraciones: Role y Gender

Tecnologías Utilizadas
Java
Programación Orientada a Objetos (POO)
Uso de herencia
Uso de clases abstractas
Uso de enumeraciones (enum)

Objetivo Académico
Aplicar correctamente los principios básicos de programación orientada a objetos, incluyendo:
Abstracción
Herencia
Polimorfismo
Composición
Organización por paquetes
